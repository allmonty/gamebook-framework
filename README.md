# Gamebook Framework

An open format for gamebooks: stories you play by choosing paths through pages, collecting items and rolling dice against your stats. A story is one JSON file; its rules (stats, dice, combat) are data inside the story, with presets for Fighting Fantasy and a d20-lite, so one engine plays many kinds of gamebook.
